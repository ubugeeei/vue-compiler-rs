# Test Suites — the canonical registry

> [!NOTE]
> Every suite a Davinci PR can be gated on, with its command, oracle type, and
> the phases where it becomes mandatory. Phase files reference these by ID.
> New suites are added here first; a gate referencing an unregistered suite is
> a plan bug. All oracles obey the assurance doctrine: exact equality,
> no partial matching.
